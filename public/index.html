Firefly 微服务框架 · 作者 / 独立开发（开源） 2026.05 – 至今

Firefly 是一个从零构建的模块化、可扩展 Go 后端微服务框架，采用分层架构，提供应用生命周期管理、多协议支持、中间件系统、统一错误处理、结构化日志、可观测性等核心能力。已通过 MIT 许可证在 GitHub 开源，配备中英文双语文档与完整 Docker 部署方案。

  • 框架架构设计：独立设计并实现了传输层、中间件层、服务层、基础设施层的四层架构，支持 HTTP（基于 Gin）和 gRPC 双协议服务器，实现动态路由、路由分组、请求/响应统一处理等核心机制。
  • 中间件系统研发：构建洋葱模型中间件体系，内置 Recovery、Logging、Tracing、Metrics、Auth、RateLimit、CORS 七大中间件，实现 Panic 捕获自动恢复、令牌桶限流（100 req/s）、日志脱敏等生产级特性。
  • 可观测性体系构建：集成 OpenTelemetry 分布式追踪、Prometheus 指标自动收集、结构化日志（slog + lumberjack 轮转）三大支柱，形成完整三位一体可观测性方案。
  • 基础设施抽象：实现文件与 Consul 双模式服务注册发现、MySQL / PostgreSQL / MongoDB / Redis 四数据库连接器统一抽象、可插拔序列化（JSON / Protobuf 切换）、编译时依赖注入容器及插件生命周期管理。
  • 工程质量保障：属性测试与传统单元测试结合，覆盖应用配置、并发管理、中间件链执行顺序等共 47 个核心属性；完成 Docker 容器化与 Makefile 构建自动化。
